Using Tiny Key Magic

Mac desktop

Use the ✨ menu-bar icon to start play, adjust play duration and optional automatic start after inactivity. Hold Escape for three seconds to start or stop play if keyboard permission is enabled. A five-second countdown appears before play begins.

iPhone, iPad and Android

Play inside the app by tapping the screen. Parents use the app's on-screen parent control to start and end sessions.

Sound

Use the sound control to turn effects on or off. Tiny Key Magic is designed to work without an internet connection.

Common questions

Why doesn't holding Escape start play on Mac?

macOS may require Input Monitoring or Accessibility permission for the desktop version. Open System Settings → Privacy & Security and review Tiny Key Magic's permissions. You can start play directly from the app's menu-bar icon if the shortcut is unavailable.

Will it change my files?

The desktop app displays a temporary animation layer and is designed not to modify the wallpaper, documents or desktop files. Operating-system keyboard shortcuts and security controls may still work.

Is there a subscription?

No. Tiny Key Magic is offered as a one-time paid download, with no in-app subscriptions or advertisements.
